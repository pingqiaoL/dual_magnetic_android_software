# 0.8.8 曲线可读性修复

日期：2026-10-20，版本码 23。

- 主图每屏由 60 秒缩短到 10 秒，每格 2 秒；拖动和点击取点使用同一时间窗口。
- 取消向上多层堆叠数值标签。标签紧贴其采样点上方，短引线明确对应点；只有极密集时省略会重叠的标签，红点与原始数据仍保留。
- 纵轴包含零，显示真实的零值水平线。
- 最后一条读数保持 1.25 秒，随后在 250 ms 内平滑下降，1.5 秒时归零，与当前读数有效期一致。新读数恢复时从零线连接至对应真实点，连续及时到达的读数正常平滑连接。
- 测量停止后仍按轮次停止时刻冻结，不继续向后计时。
- 新增 ThicknessPlot 显示投影：补充的保持/归零点不显示红点、不计入测量统计、不写入 CSV。实时和历史视图按同一规则绘制。
- 明确虚拟波形测试加入一次“测量状态继续运行，但读数暂停”的短缺测，用于检查归零和恢复。

测试覆盖持续数据、超时归零、缺测零线、恢复后真实值对应、视口外旧读数和空轮次。完整系统说明参见 [开发文档](DEVELOPMENT_GUIDE.md)，此前版本记录按原版本保留。

验证结果：31 项单元测试、Debug 构建和 Lint 执行成功；MK32 已安装 0.8.8。虚拟读数缺测/恢复实机截图保存在 `artifacts/ui-0.8.8/`，已确认 10 秒视窗、零线及红点数值关联。验证后恢复普通启动参数。

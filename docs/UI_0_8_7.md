# 0.8.7 界面更新与验证

日期：2026-10-20。版本码：22。

- 测厚主图改用保形三次曲线，连接真实离散采样点；局部极值使用水平切线，避免插值生成假峰值。超过 3.5 秒的缺测仍保持断开。
- 原始采样点显示红点，上方标注厚度。邻近标签向上错位；极密集数据省略部分标签以保持可读性，点击曲线仍可查看具体点。原始数据和 CSV 不做平滑修改。
- 视频主页面的测厚小窗只显示大号厚度值与 μm，数值按小窗宽度适配。
- 数据页面曾在白底画完后，新建空图层执行 CLEAR，随后合成空图层，白底实际未被清除，导致视频小窗被遮挡。现将 Dashboard 作为独立硬件图层，在该图层直接清除视频区域，露出原生 SurfaceView。
- 保留已有 UART、轮次保存、历史查看、视频追帧与重连策略。

验证：`testDebugUnitTest assembleDebug lintDebug` 成功，25 项单元测试通过，包括新增的曲线切线、峰值和非等间隔插值不越界测试。Lint 仍有依赖版本/旧检查器/备份规则提示，无阻塞错误。

已安装 MK32 测试，使用 USB ADB reverse 的本地 RTSP 测试球和虚拟测厚，确认主次画面切换后视频小窗显示测试图像、时间戳继续更新。该测试用于验证显示合成，不代替真实 Orin 链路的延迟测量。截图位于本地忽略目录 `artifacts/ui-0.8.7/`。

本轮测试结束后恢复默认启动参数和 Orin 地址。完整系统架构见 [开发文档](DEVELOPMENT_GUIDE.md)，其中 0.8.6 验收数字保留为对应版本的历史记录。
